# Movie Recommendation System

This project showcases a fullstack web project that includes working with datasets and using AI/ML concept to build a system that will recommend movies. 

## Installation & Setup

We will use Jupyter Notebook to run python code.

- Ensure Jupyter and Python extensions are installed in VS Code.
- Install pandas.


## How to Run

1. Open VS Code.
2. Press Ctrl+Shift+P. 
3. Type Create: New Jupyter Notebook into the search bar and hit Enter.
4. Installing the pandas : %pip install pandas.
5. Test if the pandas is installed :%pip show pandas.
